## Overview

CritAlert is an AI-driven medical alert system designed to detect critical abnormalities in medical imaging reports. The project supports X-Ray, ECG, and CT scan analysis using trained deep learning models and connects the results to a doctor-facing alert dashboard.

### Highlights

- Medical image upload and analysis
- Support for X-Ray, ECG, and CT reports
- Critical abnormality detection using trained CNN models
- Doctor login and alert management dashboard
- Local image storage and alert tracking
- Research/demo deployment ready

### Tech Stack

- Python
- Flask
- TensorFlow / Keras
- NumPy
- Pillow
- HTML / CSS / JavaScript
