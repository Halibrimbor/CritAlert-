CritAlert startup guide

1. Double-click start_critalert.bat
2. The script will create a local virtual environment if needed
3. It installs requirements automatically
4. It starts the Flask app
5. Open the browser at:
   http://localhost:5000

Doctor portal:
   http://localhost:5000/doctor/login

Default doctor password:
   doctor@1234

If Python is not found, install Python 3.10 or 3.11 and add it to PATH.
