## About this project

CritAlert is an AI-powered medical screening and alert system built to assist healthcare workflows by identifying potentially critical abnormalities in X-Ray, ECG, and CT scan images. The project uses trained deep learning models to analyze uploaded medical images and classify whether the result is normal or critical. When a critical finding is detected, the system creates an alert and sends it to a doctor dashboard for review. This project combines machine learning, Flask web development, and medical image processing into a functional prototype that demonstrates how AI can support early diagnosis and triage in clinical settings. It is designed as a research and demonstration project for healthcare technology applications, with a focus on reducing manual review time and improving alert visibility for doctors.
